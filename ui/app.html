Modelos e IA

A Aila roda local por padrão (grátis, nada sai do PC). Adicione uma chave de API para usar modelos na nuvem — nesse caso seus prompts vão para o provedor.

As chaves ficam só neste computador (config/local.yaml), nunca no repositório.
